# Session 10 - TCP Client-Server Chat

## Topic
TCP Client-Server Chat

## Description
Socket programming, network communication, multi-threaded server

## Files
- `LabSession10.java` - Main launcher
- `ChatServer.java` - Server implementation
- `ChatClient.java` - Client implementation

## How to Run
```bash
# Option 1: Use launcher
javac LabSession10.java
java LabSession10

# Option 2: Run separately
javac ChatServer.java ChatClient.java
java ChatServer    # Terminal 1
java ChatClient    # Terminal 2
```
